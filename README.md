# 🔐 Password Security Analyzer

A Python-based Password Security Analyzer with a graphical user interface built using Tkinter.

## Features

- Checks password length.
- Checks for uppercase letters.
- Checks for lowercase letters.
- Checks for numbers.
- Checks for special characters.
- Rates password strength.
- Provides recommendations for improving passwords.
- Includes Show/Hide password functionality.

## Technologies Used

- Python
- Tkinter
- Regular Expressions (re)

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python password_gui.py
```

To run the command-line version:

```bash
python password_checker.py
```

## Project Purpose

This project was developed to practise Python programming and understand basic password security principles.

**Note:** This is an educational password strength checker, not a complete password security solution.
